# Photos de fond des rubriques (bibliothèque)

Déposez une image nommée par le *slug* de la rubrique pour l'afficher en fond de sa tuile.
Sans fichier, un dégradé thématique est utilisé automatiquement.

Format : JPG, ~800×400px, nommé `<slug>.jpg`. Slugs actuels :
- code-electoral.jpg
- lois.jpg
- decrets-reglements.jpg
- ordonnances.jpg
- rapports-cena.jpg
- textes-historiques-jo-1960-1982.jpg
- archives.jpg
